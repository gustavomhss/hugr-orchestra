## Delegated Integration

- `WP-5.17.TOOLS` belongs to Orchestra. Atlas keeps opaque `EmitApi.absorb`; Orchestra defines `ResultCard`
  and wave-close driver.

Focused evidence and manual decisions live in `wp-status-overrides.json`; script validates every override
against an existing card and requires non-empty evidence.

## Closure Rule

Mark card `BUILT` only after cold review confirms source implementation, acceptance tests, held-out coverage
where applicable, all module gates, scope ownership, and a merged commit. Mark out-of-band cards separately;
do not inflate campaign completion with remediation evidence.

Run `npm run wp-audit -- --json` for per-card evidence rows.
