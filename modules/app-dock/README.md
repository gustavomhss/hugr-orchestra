# @orchestra/app-dock

MCP Dock and Linux workspace tools: the hooks that let an agent read and operate desktop apps over the Electron main channel.

## Purpose and ownership

MCP Dock and Linux workspace tools: the hooks that let an agent read and operate desktop apps over the Electron main channel. Owner: The MCP Dock owner.

Sources live in `src/`. `createAppDockHooks` and `createLinuxWorkspaceHooks` take a `Transport` (`src/transport.ts`). `AppDockTools.contribution` (`src/application-tools.ts`) registers both as core Tools on V2 and, through its `app-dock/linux-reaper` node, sends `linux.session.close` when a Session is deleted.

## Public entry points and consumers

Exports are explicit keys derived from the source wildcard in the module registry. Consumer is the composition root apps/cli.

## Dependencies and boundaries

Layer `product`: it may import foundation, native, library, contract, extension-api, module, platform and product packages, never composition or app packages.

## Assets, schemas and generated files

None yet.

## Persistence, identity and lifetime

None of its own; the host owns persistence and process lifetime.

## Commands

Tests run on GitHub Actions through `bun run test:ci app-dock` from the repository root.
