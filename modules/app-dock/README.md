# @orchestra/app-dock

MCP Dock and Linux workspace tools: the hooks that let an agent read and operate desktop apps over the Electron main channel.

## Purpose and ownership

- `createAppDockHooks` (`src/app-dock.ts`) and `createLinuxWorkspaceHooks` (`src/linux-workspace.ts`) take a `Transport` (`src/transport.ts`) to Electron main.
- `AppDockTools.contribution` (`src/application-tools.ts`) registers both as core Tools on V2 and, through its `app-dock/linux-reaper` node, sends `linux.session.close` when a Session is deleted.
- The main-process side lives in `apps/desktop/src/main` (`app-dock*`, `ipc-app-dock*`, `linux-workspace*`).

## Public entry points and consumers

- Export keys `./app-dock`, `./app-dock-linux`, `./application-tools`, `./dock-mcp`, `./linux-workspace` and `./socket-transport`.
- `apps/cli/src/host.ts` registers `AppDockTools`; `apps/cli/src/commands/handlers/serve.ts` opens the channel with `AppDockSocket`; desktop tests and proofs import the hooks.

## Dependencies and boundaries

Layer `product`: it may import foundation, native, library, contract, extension-api, module, platform and product packages, never composition or app packages.

## Assets, schemas and generated files

- No generated files. The Linux accessibility helper payload is under `apps/desktop/resources/linux`, not here.

## Persistence, identity and lifetime

- None of its own. A `serve` child gets a loopback WebSocket URL and a per-launch token from Electron main (`ORCHESTRA_DOCK_URL`, `ORCHESTRA_DOCK_TOKEN`); outside the desktop there is no channel.

## Commands

- `bun run test:ci app-dock` from the repository root.
- `bun typecheck` in this directory.
