# Inventory recipe

Enumerate the baseline root tree, then native, then native/omni recursively through GitHub MCP. Reject truncation or any count other than 426 blobs, 33 exact user exclusions and 393 unique remaining paths. Verify every captured source with Git SHA1 of blob header plus bytes, SHA256 and exact size. Map each source to one active authored record and its source evidence; excluded paths remain support-only.
