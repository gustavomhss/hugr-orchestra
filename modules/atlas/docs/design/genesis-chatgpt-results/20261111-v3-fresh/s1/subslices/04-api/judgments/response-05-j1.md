### Limites da liberação

O PASS permite **produzir L2 local**; não concede aceite antecipado a L2, integrações Core, Atlas, consumidores, CI ou execução. Permanecem obrigatórios os gaps condicionais de F02 e as obrigações F03–F08 para os claims dependentes, inclusive o vínculo Atlas indicado.

O frame histórico apresentado é parte necessária desse alcance: leituras antigas não se tornam releituras atuais, e as notas extensas retiradas não voltam a ser claims promovidos. **A gravação anunciada desse frame e dos juízos atuais em `authority.basis`/provenance continua uma obrigação de entrega; este parecer não afirma que essa gravação já ocorreu.**
