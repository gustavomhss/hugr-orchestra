# Pacote anterior à integração Core

Registro imutável do pacote de 13 artefatos usado nas primeiras operações prepare/read/index. O arquivo native-package.json é preservado como registro de seus bytes originais; seus body.path são os paths originais no namespace no momento da operação, não caminhos relocados para executar este arquivo nesta pasta. As revisões de L3/L4 correspondentes são preservadas pelo produtor. As operações finais receberão o pacote atualizado e recibos novos.
