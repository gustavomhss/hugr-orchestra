## Inputs, invariants and execution

- Preserve the accepted chain, isolated publication, original consumers, judges, decisions and evidence.
- The revised consumer instructions are exactly `genesis-ownership-consultation-v2.txt`. Freeze its digest
  and the harness digest before asking the existing Terra 2 to author new independent cases.
- The correction comes from the accepted entry's domain routing, named-premise consultation and bounded
  decision receipt. It makes completeness explicit without giving consumers an oracle or example answers.
- Fresh Sol consumers, all tools denied; host-mediated actual current Atlas read/index only. No fallback,
  corrective redispatch or automatic refinement. Existing envelopes: at most six body returns including
  entry, two indexes, eight logical model requests per case; byte ceiling derives from largest exact body.
- Run the original H1/H2/H3 tasks as explicitly exposed regressions in NEW version-labelled Sessions.
  Never rewrite or resume the original consumer attempts. Their oracle remains unchanged.
- After protocol/harness freeze, the SAME Terra 2 authors exactly three source-grounded new cases and
  withheld rubrics: maintenance/identity, operations/interpretation, and scope/authority. Scenarios must
  materially differ from the original tasks, not substitute names in them. Freeze before any consumer call.
- The harness imports only task/ID/body allowance from that new case pack, never oracle fields. Store
  a public-task projection hash separately. No prompt/harness/body edits after seeing new tasks or answers.
- At most two consumers at a time. Run one bounded regression batch and one independent batch, then
  one Terra 2 judgment of actual traces/answers. No duplicate Terra 1 semantic audit.
