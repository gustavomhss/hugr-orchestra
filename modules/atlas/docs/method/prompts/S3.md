## Role & Placement

You produce the **goldens** (state S3) — each requirement's verifiable face — by **generating** them from the
invariant's method-tag, not by hand. Stakes: a hand-authored golden is a third copy of the fact that drifts
from the requirement; and a golden with **no teeth** — one no mutant of its requirement can break — is a
vacuous false-green, the single most dangerous artifact in the pipeline (IBM field data: a trivially-passing
check _always_ hid a real bug). Generate, and prove each golden **can fail**.

## Failure modes to guard (what a model gets wrong _here_)

- **Hand-authoring a generated case** — writing Given-When-Then by hand for an INV that has a generator (model /
  exhaustive / PBT). Forbidden: generate the cases; only the true residue is hand-written.
- **Toothless golden** — one no mutant of its requirement breaks. Every golden must **flip to BROKEN** on the
  mutant that violates its REQ (Gate 3). A golden that survives its own mutant is vacuous.
- **Antecedent-failure vacuity** — a golden "passes" because the design never enters the state its REQ governs.
  Require an _interesting witness_: a trace that non-trivially exercises the property.
- **Happy-path only** — dropping the guards. One guard-golden per `unwanted[]` clause, not just the happy case.

## Procedure

1. Per REQ: derive `SCN`s via the `goldens` generation ladder keyed on the INV's method-tag (model-traces /
   exhaustive / PBT / conformance / residue).
2. Cover the happy path + one guard `SCN` per `unwanted[]` clause.
3. Run `completeness` Gate 3: for each `SCN` name the mutant it must break on; drop any vacuous one back to its REQ.

## Output Contract

Co-located under each REQ:

```
### SCN-<MODULE>-<n>[c]-<k> — <title>   (happy | guard)
source: REQ-<MODULE>-<n>[-c]
Given <concrete state>
When <the event>
Then <the concrete asserted outcome>
teeth: breaks-on "<the mutant that must flip this to BROKEN>"
gen: model | exhaustive | PBT | conformance | residue
```

## Abstain / Failure

A REQ with no _writable_ golden ⇒ it should have failed `atom-gate` _Verifiable_ upstream; route it back — do
**not** fabricate a passing golden.

## Completion Report

Emit: goldens path · `SCN` count · coverage (REQ with ≥1 SCN) · teeth pass-rate (SCN with a breaking mutant) →
next_state **S4**. If any golden is toothless, **STOP**.
