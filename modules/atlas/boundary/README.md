# @orchestra/atlas-boundary

Generated bundles that expose Atlas to Orchestra.

## Purpose and ownership

- Generated JavaScript and `.d.ts` bundles that expose Atlas to Orchestra.
- Owner role: Atlas maintainer.
- Atlas sources live in `modules/atlas/packages` and are not owned here.

## Public entry points and consumers

- Export keys `.`, `./materialize`, `./native-header` and `./native-memory`; every target is in `modules/atlas/boundary/src/generated`.
- Consumer: `apps/orchestra`.

## Dependencies and boundaries

- Layer `module`.
- No workspace dependencies.

## Assets, schemas and generated files

- `modules/atlas/boundary/src/generated` is produced by `bun run generate` (`modules/atlas/boundary/script/build.ts`); never edit it by hand.
- `modules/atlas/boundary/src/generated/native-header.js` and `modules/atlas/boundary/src/generated/native-memory.js` are listed in `script/spawn-allowlist.json`.

## Persistence, identity and lifetime

- No persistence here; the Atlas store is owned by Atlas.

## Commands

- `bun run generate`
- `bun run check:generated`
- `bun run test:ci atlas-boundary <files>`

## Contracts and verification limits

- `bun run check:generated` checks that the generated files are byte-equal to a fresh build.
