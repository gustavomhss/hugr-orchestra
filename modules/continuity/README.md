# @orchestra/continuity

Engine-neutral continuity helpers: transcript aliases, archive search, dry transport, raw payloads, request sources and masking.

## Purpose and ownership

- `src/v2` holds the V2 strategy: it replaces core Session compaction (`ContinuityStrategy`) and adds the `context_recall` and `context_compact` tools (`ContinuityTools`). `alias.ts`, `archive.ts` and `masking.ts` support them.
- `src/archive-search.ts` ranks archived chunks by lexical match; `src/masking-rules.ts` holds the rules for which tool output stays verbatim.

## Public entry points and consumers

- Export keys `./v2` (`ContinuityV2.contribution`), `./archive-search` and `./masking-rules`.
- `apps/cli/src/host.ts` registers `ContinuityV2.contribution`.

## Dependencies and boundaries

Layer `product`: it may import foundation, native, library, contract, extension-api, module, platform and product packages, never composition or app packages.

## Assets, schemas and generated files

- No generated files. `src/v2/tools.ts` defines the schemas of the two tools.

## Persistence, identity and lifetime

- None of its own; archived context is written through `@orchestra/atlas-boundary/context` and the host owns persistence and process lifetime.

## Commands

- `bun run test:ci continuity` from the repository root.
- `bun typecheck` in this directory.
