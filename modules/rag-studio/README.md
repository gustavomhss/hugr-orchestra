# @orchestra/rag-studio

Source admission and shared storage contracts for Rag Studio. This integration contains the existing admit implementation and its focused tests. The host adapter, HTTP group and chapter are pending.

## Contract and ownership

The frozen contract is `docs/specs/rag-studio/CONTRACT.md` and `docs/specs/rag-studio/seam.ts`, version `fb61d451`. `src/seam.ts` is a byte-identical package-local copy so type imports stay inside the package boundary. Import and re-export its types only: its function bodies are stubs, not engine entry points.

`src/context.ts` is shared and lead-owned. The package root exports that context; `src/admit.ts` implements `admit` and `listSources`. The work-package ownership list remains in `docs/specs/rag-studio/work-packages.md`.

## Persistence and verification limits

The supplied `memoryStore` uses Maps and caller-supplied text and permissions. The table declarations in `packages/core/src/rag-studio/sql.ts` are preserved, but this integration does not connect them to a persistent Store, register a migration, or activate a chapter. The admit tests exercise the memory implementation; they do not establish real filesystem, PermissionV2 or SQLite behavior.

The owner still judges Board J1 before work on the visible RAG cockpit. RAG J01–J10 remain human judgments as well.

## Commands for the lead

From this directory: `bun typecheck`.

From the repository root: `bun run test:ci rag-studio test/admit.test.ts --os both`.

Check the local seam copy against the documentary seam before accepting a contract change. Keep the copy identical and do not export the stub functions. No test or CI result is asserted by this source integration.
