# @orchestra/rag-studio

Admitted-document studio. Word search, the cut, and the four lights. Embedding stays off. Project source stays out.

## Purpose and ownership

- Behavior lives in `modules/rag-studio/src`, one file per work package in `docs/specs/rag-studio/work-packages.md`.
- `src/context.ts` is the lead-owned store. Work packages import it and do not edit it.
- Tables live in `packages/core/src/rag-studio/sql.ts`. The HTTP group is `packages/protocol/src/groups/rag-studio.ts`.

## Public entry points and consumers

- Export key `.` (`src/context.ts`) until the barrel lands.
- The server handler reads the tables. The chapter is `packages/app-shell/src/orchestra/chapters/rag-studio/page.tsx`.

## Dependencies and boundaries

Layer `product`: it may import foundation, native, library, contract, extension-api, module, platform and product packages, never composition or app packages.

## Assets, schemas and generated files

- No generated files in this package. Wire schemas are `packages/schema/src/rag-studio.ts`.

## Persistence, identity and lifetime

- Rows live in the Orchestra SQLite database. A source id is stable for one location and path. Embedding has no column.
