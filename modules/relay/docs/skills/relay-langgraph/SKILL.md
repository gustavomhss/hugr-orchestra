# Relay gates for LangGraph

## Trigger

Use for `lib/orchestra_relay/`: `gated()`, its check and approval nodes, the external ledger writer, the
`verify` and `demo tamper` commands, and the quickstart example.

## Contract

- Ledger bodies follow `packages/schema/src/relay-external.ts`; lines must pass `src/ledger/verify.ts` as written.
- `lib/orchestra_relay/verify_ledger.py` is a byte-identical copy of `benchmark/verify_ledger.py`; a test fails on drift.
- `test/golden/external/python/ledger.jsonl` is regenerated by the tests and read by the TS read side.

## Cold review

- Does a gated node's static out-edge still run on unchecked output?
- Does resuming an approval re-run the user's function, a check, or a ledger append?
- Do the honest limits in `lib/orchestra_relay/README.md` still match the code?
