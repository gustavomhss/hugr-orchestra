# Backend codegen

Run an engine only as `"$BACKEND_TOOLKIT_BIN/<id>"` and only for artifacts the packet assigns. Open the group, then the one engine.

- `--check` or `--verify` alone does not generate: produce the assigned artifact first, then run the check.
- Generate only affected artifacts; a skeleton is not completed behavior.
- Copy a failure `error.code` into a `tool` blocker. Inspect partial or unknown effects before another mutating call; never replay blindly.
