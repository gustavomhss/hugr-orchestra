## Host contracts

`app-dock-native-protocol.ts` is the import/type/codec/limit anchor; shared reply goldens live in `test/native/contract`. Startup reply uses ID `hello`. Helper epoch and session ID are required; requests use monotone send-time canonical IDs. `Call` args are validated by operation in guest and adapter. Guest `bind` phases:

- discover: `{phase:"discover",identity:DockIdentity,target:Target}` -> `{status:"proposal",proposalID,roots:[{owner,path,name,role}]}`. At most eight live proposals, 10-second expiry; discover matches actual process identities and only proposes concrete application child windows.
- confirm: `{phase:"confirm",proposalID,roots:[{owner,path}],ownershipRevision}` -> `{bindingID,bindingEpoch,appID,launchEpoch}`. Freshly verify confirmed subset of proposal and process/native identity; expire/consume proposal. No actions before bound.
- read args: ReadQuery. action args: `{ref,actionID?}`. type args: `{ref,text,mode?:"editable"|"keyboard"}`. unbind needs binding ID/epoch. cancel args `{requestID}`; shutdown args `{}`. Controls bypass semantic queue; no second concurrent semantic provider operation.

`NativeDockClient.create(channel, config?)` -> Promise<NativeDockClient implementing Client>; `hello`, `request(Call, signal?)`, `close():Promise<void>`.
Channel writes raw Uint8Array asynchronously with backpressure, subscribes stdout/exit with cleanup, and `terminate():Promise<void>` resolves only after reaping. Exit reason may be helper-resource-exit. Startup <=5s; per-request <=10s including queue; cancel grace <=1s, then retire/reap stuck helper. Promise settlement retains semantic slot until guest terminal/reap. All listeners/timers/queues/frame buffers bounded and removed on close. Control sequencing serialized with writes, not queue admission. Fatal protocol errors retire helper. Late terminal results only release original slot, never another binding.

`NativeDock` class in `app-dock-native.ts` implements `bind(identity,target,client,confirm:Confirm)`, `unbind(identity):Promise<void>`, `has(identity):boolean`, `dispatch(op,identity,args:Record<string,unknown>,signal?):Promise<JSONValue>`, `metadata(identity)` and `close():Promise<void>`. Confirm callback consumes Proposal and returns host-confirmed Handle subset; always required. Check identity fields, session/epoch, target evidence, typed binding/proposal replies. Capacity eight bindings; no fallback. Browser-only ops return unsupported-operation. read/click/action/type/wait supported; wait is delay, not postcondition. Numeric refs on native scope and native refs on foreign scope reject. Adapter is not responsible for viewer activate/close/list: RPC lead owns those integration sites.
