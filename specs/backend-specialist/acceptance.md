Test presence is not test execution: a test counts only where a run is cited.

Status words:

- **qualified**: the cited observation happened, and only that.
- **source-only**: code and tests inspected, no matching recorded execution.
- **landing**: the PR is open; the clause stays open until it merges.
- **unqualified / refused**: a required observation is missing, or the interface refuses it on purpose.

These are accepted limits, not work items.

- Cassandra exact-endpoint runtime is proven on Darwin only. Linux and Windows stay HOLD. Windows POSIX-only fixture branches are not runtime proof.
- Scylla runtime, ARM execution, and in-flight Go cancellation or write-deadline expiry are unqualified.
- Whole-closure OS and libc floors and baseline-CPU refusal are not implemented. The selector does not check AVX2.
- The F3 live-model continuity chain (checkpoint, resume, compaction with a real model) was not observed. Compaction is proved with synthetic replies only.

- No new full 21/21 model campaign exists. Use the per-case PASS pointers in E4; do not average archived attempts into a rate.
