## Goal
The chapter's transport calls `review` and the eight review writes. The controller loads `review` with the snapshot and
rereads both after every write (D34; D6 still exempts `verify`). It exposes `hold`, `release`, `propose`, `decide`,
`answer`, `memoryDecide`, `territory` and `delegate`. The controller test and the Playwright fake server know `review`.
