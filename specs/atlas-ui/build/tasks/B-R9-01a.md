## Goal
`node harness/gates/own-snapshot-guard.mjs --worklist <file>` writes `{units: [{unit, stale: [path]}]}` — every snapshot
unit with a source anchor whose current blob differs, is missing or is not a regular file, units and paths sorted —
before it judges anything else, then gives its usual verdict and exit code (D24). With no argument it is unchanged.
