   `../src/write/upsert.js`, type `WriteRequest` from `../src/write/router.js`. Helper:

   Cases:
   1. CONTROL (same tier, no replace): `upsert(upsert(emptyStore(), write("h1", "old claim")).store, write("h2", "new claim")).store

      (the old bytes stay addressable).
   3. REPLACE ON CREATE: `upsert(emptyStore(), write("h1", "only claim", { replace: true })).store.current.get("nk-adv")!.claims`
      equals `["only claim"]` and the decision is `"CREATE"`.
   4. AUTHORITY UNCHANGED: seed `write("h1", "t1 claim", { tier: "T1" })`, then `upsert(seeded, write("h2", "t2 claim", { replace: true }))`
      (tier T2, weaker) throws `GovernanceAuthorityError` whose `.reason` is `"governance-downgrade"` (assert with
      `try/catch` on `.reason`, or `expect(() => …).toThrow(GovernanceAuthorityError)` plus a second call reading `.reason`).
   5. RELOCATION UNCHANGED: `write("h2", "x", { replace: true, scope: "other" })` over a `core` seed throws with `.reason`
      `"governance-relocation"`.
