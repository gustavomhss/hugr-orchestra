Audit-grade code review methodologies used by professional security and code audit firms and programs: what techniques do they combine, and which can an AI reviewer replicate? Use primary sources (published methodologies and public reports from Trail of Bits, NCC Group, Cure53, Include Security, X41, OSTIF-funded audits, OpenZeppelin, Spearbit, Code4rena/Sherlock contest rules, Google Project Zero, the Trail of Bits Testing Handbook, and Semgrep/CodeQL variant analysis guides).
