## IMX01 — biblioteca, host e segredos

Usar somente superfície pública de `@azure/msal-node@7.1.0`, import lazy. Novo cliente por exchange, cache inicial vazio, sem cachePlugin persistente ou deserialize de JSON de request. PCA para desktop público sem secret; CCA para servidor somente com certificado/chave host configurados e validados antes de gastar code (thumbprint SHA256, par RSA >=2048 e validade X509). Não acrescentar client secret fallback, private key em manifesto/renderer, ROPC, SP/MI ou broker. Certificados de fixture não são registros Entra autorizados.

Adapter interno recebe perfil admitido IDP01, configuração de transporte host-owned e verificador IDV carregado pelo host; recebe `{code, material}` somente do backend. Material é o retorno IXM, nunca nonce/verifier/scopes de JSON UI. O adapter isolado **não** prova que seu chamador consumiu ticket, tem Authority ou Location: isso pertence a IMX02. Capturar valores da operação, não permitir retarget por mutação. Reexecutar o mesmo Effect não pode reenviar um code; falha/timeout/cancelamento não gera retry automático. Um host malicioso que chame outro adapter continua fora da garantia local de ticket: não registrar esta superfície em ferramentas/rotas.

MSAL auth authority organizacional pública fixa, redirect/clientID/scopes/correlationID originais, PKCE verifier e nonce esperados. INetworkModule interno nega GET/discovery inesperado; POST só para `/organizations/oauth2/v2.0/token` em `login.microsoftonline.com`, com **somente `?client-request-id=<correlationID protegido>`** que a MSAL 7.1.0 acrescenta. Adapter exige a URL exata sob o correlationID original; transporte exige o mesmo valor em `NetworkRequestOptions.correlationId`, sem parâmetros extras, duplicatas, path alternativo ou host de callback. Um único POST por operação, `disableInternalRetries:true`, logger silencioso/PII off. Endpoints/token URL de metadata, callback hints, token claims e headers nunca escolhem destino. Não usar default networkClient (redirect/retry/trace próprios não qualificados). Cancelamento atravessa `transport.bind(signal)` call-owned, sem Context/Authority; o child contextual que admitirá o envio ainda pertence a IMX02.

Transporte token implementa HTTPS real com TLS >=1.2, Host/SNI/verificação fixos, default DNS/trust nativos e mesma configuração IP/porta/CA **host-only** de IJW quando explicitada. Form URL encoded <=32 KiB, sem Authorization/Cookie/client cert nativos; certificado CCA assina client_assertion pelo MSAL, não mTLS implícito. Resposta <=256 KiB/headers <=16 KiB, status/media/encoding/UTF-8/partial/redirect/timeout/abort explícitos. Code/PKCE/assertion só saem depois de TLS verificado. A biblioteca pode receber erro remoto tipado, mas erro final não reflete body/token/nonce/chave/upstream text. Native TLS fixture/proc-fd oracle medem envio/cleanup; não inventar erro de cliente a partir do writable do servidor, nem ignorar handshake sockets.

## Identidade e cache candidato

`AuthenticationResult.idTokenClaims` é dado já decodificado, **não** prova de assinatura. Verificar `result.idToken` pelo IDV com nonce/createdAt e pins protegidos. Exigir account não nula, result.tenantId/account.tenantId, result.uniqueId/account.localAccountId coerentes com tid/oid assinados e environment público canônico; homeAccountId é identificador opaco MSAL limitado, não oid reconstruído. Guest pode ter home tenant/uid diferentes do recurso: não impor falsa igualdade home uid == resource oid. Nomes/username/email só labels, nunca identidade ou permissão.

**Fatos observados da versão pinada:** metadata bundled tem `preferred_network: login.microsoftonline.com` e `preferred_cache: login.windows.net`. Aceitar apenas esses dois environments, emitir account externo canônico e **não reescrever o cache opaco**; roundtrip real confirma alias original. CCA com thumbprint SHA256 assina **PS256**, não RS256 dos ID tokens. `TimeUtils.nowSeconds()` da MSAL usa `Math.round`, enquanto JOSE usa floor: verificação da assertion sintética admite **um segundo** de tolerância e exige lifetime 600s/diferença nbf–iat <=1. Isso não relaxa o IDV nem TLS. Certificado/chave reais da fixture são gerados antes de atualizar o relógio da validação; par incompatível e certificado fora da validade recusam. Adapter reavalia a validade antes da operação e após resposta, sem usar privateKey da UI.

Access token Microsoft é opaco; não parsear JWT/claims para autorizar Fabric. Validar os metadados da resposta MSAL (Bearer, expiry futuro, scope Fabric solicitado, sem substituição por outra superfície); operação remota futura ainda exige guard/capability/scope apropriados. ID token não concede os direitos da API. Cache só pode ser serializado pelo método público **depois** de sucesso de rede + IDV + account + resposta válida. Erro/retorno negado não serializa nem escreve nada; não usar finally hook `cacheHasChanged` como autorização de persistência.

Retorno IMX01 privado efêmero: proof IDV emitida pelo verificador configurado, campos mínimos de account e serialized cache candidato limitado a 1 MiB no formato MSAL 7.1.0. Nunca refresh/access/id token soltos num DTO/progresso/modelo/log; serialized também é segredo, não prova de storage cifrado. IMX03 transformará o candidato no Credential.Cache cifrado existente com binding contextual/CAS, não uma nova tabela/arquivo refresh-token.

## IMX02 — regra para callbacks da biblioteca

Não executar `Effect.runPromise` dentro de INetworkModule supondo que Current/Location seguiram a Promise; `CapabilityOperator.validate` consulta o frame runtime real. Não guardar services/context/Authority em singleton para ativar provider depois. Preferir bridge **call-owned de um POST**, com fila limitada e Promise resolver contendo apenas request/response, processada por child Effect que herda a invocação atual e a Scope do exchange. Revalidar naquele child antes de abrir o POST e checar latch ativa/abort. Scope fechado rejeita callbacks tardios e desfaz socket; nenhum callback retoma request de outro frame. O code ticket continua sendo IDA03, nunca a fila ou uma Proof. Essa composição será aceita por teste real de revogação entre consumo/construção/TLS/envio/retorno, não inferida da biblioteca.
