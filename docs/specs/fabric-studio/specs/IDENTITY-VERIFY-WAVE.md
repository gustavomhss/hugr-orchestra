## Contrato congelado

- `verify({token, nonce, createdAt, tenantID?, objectID?})` recebe expectativas do host protegido. Copiar os valores na construção do efeito; nada autoriza nonce/conta vindos do callback. ID token compacto até 64 KiB, três segmentos, header tip JWT/alg RS256/kid explícitos. Recusar embedded jwk/jku/x5u e crit não suportado; não consultar URLs do header/claims.
- JWKS objeto com 1–32 chaves RSA públicas, kid único limitado, use sig/alg RS256 quando declarados, exponent AQAB, modulus real 2048–4096 bits. Limite JSON 256 KiB e campos/certificados finitos. Campos privados d/p/q/dp/dq/qi e shapes ambíguos recusados. Não implementar RSA/signature manualmente: import/verify são JOSE/WebCrypto reais. Campo issuer de chave, quando presente, deve ser exatamente o issuer validado ou o template público `https://login.microsoftonline.com/{tenantid}/v2.0` expandido para aquele tenant; assinatura correta de chave de outro issuer não basta.
- Claims obrigatórias assinadas: ver 2.0; aud string igual ao clientID do perfil; tid UUID organizacional (recusar o tenant consumer MSA); iss exato `https://login.microsoftonline.com/<tid>/v2.0`; oid UUID, sub não vazio limitado; nonce base64url de 32 bytes comparado timing-safe ao valor esperado. Tenant/object esperados, quando pinados, devem coincidir. Nomes, email, preferred_username, roles e endpoints de claims distribuídas são ignorados e nunca concedem permissão ou disparam fetch.
- iat/nbf/exp inteiros seguros; exp ainda futuro no relógio host, exp > iat e nbf; nbf/iat no máximo 60 s no futuro; iat não anterior a createdAt da tentativa menos 60 s. Não exigir auth_time recente: SSO real pode ter autenticação anterior à emissão deste ID token. createdAt/nonce/now são expectativas host, não campos escolhidos pelo token. Clock inválido é unavailable; rejeição crypto/claims é denied genérico, sem refletir token, nonce, chave ou erro upstream.
- Resultado Proof runtime imutável contém apenas clientID/issuer/tenantID/objectID/subject/expiresAt; sem token/nonce ou claims livres. `owns(unknown)` verifica identidade de objeto emitida por **este verifier**, não cópia/JSON ou proof de outra key configuration. Proof **não é Authority** nem permissão Fabric, não verifica audience de access token e não vincula conexão/conta MSAL sozinho. Não exportar esquema wire desse handle nem registrar ferramenta/rota.
