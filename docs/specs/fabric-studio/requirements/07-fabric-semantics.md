# Requirements — semântica Fabric e cobertura

Todos os itens são propostas; M = cenário mecânico futuro, não executado. Requisito de cobertura exige disposição explícita, não implementação de todas as APIs. Onde uma operação é oferecida, os limites abaixo são obrigatórios. Disponibilidade/handoff não satisfaz conclusão operacional E2E.

## Inventário sem omissões silenciosas

| ID / método | Obrigação | Aceitação observável | Contraprova | Origem / pendências |
| --- | --- | --- | --- | --- |
| FS-FAB-001 / M | Cada família mapeada deve ter disposição mantida e contextual. | F01–F33 têm objetivos/operações, suporte documentado, implementação, qualificação e contexto separados; ausência é nomeada. | Inventário com nome de workload não é apresentado como suporte total nem família é apagada por não ser lançada. | D:P06; D:A18; F:F01–F33; D:Q08 |
| FS-FAB-002 / M | Cobertura deve distinguir controle, definição, dados e execução por operação. | Sucesso de CRUD/listagem não habilita automaticamente query, publish, jobs, artifacts ou cancel. | Um editor JSON universal não substitui ferramentas especializadas quando o modelo mental é incompatível. | D:P02; D:§7; F:F01–F33 |

| FS-FAB-017 / M | Segurança efetiva deve ser revisada por superfície e identidade leitora pertinente. | Checks distinguem workspace/item, SQL, OneLake, RLS/OLS e limitações de grupos/identidades não resolvidas. | Query como Admin/Member/Contributor não demonstra RLS de Viewer; simulação não suportada não é impersonation real. | F:F25; F:C03; D:J06; T:T17–T19 |
| FS-FAB-018 / M | Catalog/lineage/scanner/Purview devem manter alcance e mecanismos separados. | Resultado informa origem, cobertura e lacunas; labels não são convertidos em segurança universal de exportação. | Scanner admin não é pré-requisito silencioso nem ausência de lineage prova ausência de dependência. | F:F24; T:T01; T:T18 |

| FS-FAB-020 / M | Telemetria nativa deve usar fonte cujo consumo externo seja suportado. | T16 mostra métricas/unidades/proveniência reais de fonte suportada ou indisponibilidade/handoff nomeados. | Modelo semântico do Capacity Metrics app não é consultado como fonte do painel próprio; preço ou atribuição ausentes não são inventados. | F:F26; T:T16; R:restrição Capacity Metrics |
