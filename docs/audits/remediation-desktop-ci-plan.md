# Desktop cold CI decomposition

The original cold epic did not qualify Desktop: Linux's combined library lane timed out after eight minutes without a completed Desktop group. Windows actually completed758 Bun cases and203 Node cases with zero failures, but258seconds of setup plus644.825seconds of task execution exceeded the900second inclusive job budget. The cancellation is not evidence of a leaked test process. Increasing timeouts is excluded.

Root freezes three deterministic Bun file shards and one separate Node lane on each OS. Desktop leaves the Linux library complement and the Windows monolithic task. Preserve the existing unit10 plus E2E5 concurrency ceilings and all Omni producer dependencies. Each Bun shard uses the existing real preload in suite mode, with one distinct existing real process control anchored per bin: `omni-process.test.ts`, `owned-serve.test.ts`, `owned-serve-omni.test.ts`. Every discovered Bun file appears exactly once; no shard is empty. Discover from the current tree and respect the existing bunfig standalone and Node exclusions. Unknown exclusion syntax must fail rather than silently omit tests.

The separate Node lane executes the existing complete `node --experimental-strip-types --test "src/**/*.node.test.ts"` command. Desktop exposes `test:bun` and `test:node` while `test` remains their full composition. Turbo's new task configuration preserves the existing test environment/input/cache contract. No case, assertion, fixture timer, retry, skip or Omni expectation changes. Existing per-case timeout behavior remains unchanged. New lanes retain existing bounded CI budgets; do not add a timeout exception.

The planner uses its existing balancing mechanism. Refresh timing weights from actual retained cold Bun output when available; moved cases inherit their measured durations under their new file owner. Mark source-run provenance and estimates honestly, without presenting estimates as new measurements. Extend JUnit collection/refresh to accept Desktop's `src/` and `scripts/` paths. Package filtering must select all four Desktop lanes for `@orchestra/desktop` and none for unrelated packages.

Acceptance covers complete union/no duplicates, excluded standalone and Node files, three real control anchors, exact Node command, package filtering, concurrency and existing Core planning behavior. Root reviews the final matrix and scopes hosted tests before the final cold epic. No local test or build execution is authorized.
