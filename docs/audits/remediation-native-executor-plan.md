# E10 isolated native executor — architectural decisions

Production GO remains withheld until the exact typed protocol, compilable scaffold and acceptance review are frozen. This stage extends the qualified parser, absolute deadline and native process capability; none of those preparatory gates closes E10.

CodeMode remains independent of Core. Its optional Context.Reference executor defaults to undefined. Core will provide an explicitly selected AppProcess-backed Layer; no current production caller is claimed to select it. An execution with a finite deadline cannot execute a native regular expression in the parent. Without the provider it refuses with the existing InterpreterRuntimeError/ExecutionFailure diagnostic and an explicit unavailable message, without adding a DiagnosticKind. This is a deliberate availability change for timed regex, to be documented and tested. Untimed execution retains its current native path.

Finite regex parsing uses the qualified private Acorn path without native construction. Finite regex values hold metadata; isolated construction validates and canonicalizes source/flags. Literal, constructor, copied host regex, property access and coercion must all avoid recompilation in the parent. Preserve the existing exposed properties, aliasing, lastIndex and public serialization; do not expose metadata as new enumerable keys. Do not claim general preemption of synchronous parsing, serialization, copying or other parent CPU work.

The typed native operations are construct, test, exec, match, matchAll, search, split, replace, replaceAll, collectReplace and collectReplaceAll. Native String methods with implicit pattern compilation are included. Replacement callbacks remain in their original parent Effect/Scope after isolated native enumeration completes; no tool, callback, interpreter or user-supplied code is shipped to the child. Callback input is reconstructed from the original parent subject, rather than repeated per match in the wire. Captures and named groups preserve undefined with explicit tags; preserve absent versus empty groups, UTF-16 offsets and internal match array index/groups. Do not prematurely apply public copyOut, which intentionally drops array metadata. Native enumeration updates lastIndex before callbacks; later callback mutations must not be overwritten by a stale reply. Full parity cases are mandatory, including constructor errors, empty/Unicode/sticky matches, replacements and clone-preserving operations.

One semaphore belongs to each execute suspension, never the provider or process. Construct each native request after acquiring its permit so aliases observe the latest lastIndex. Capture the complete operation outcome, join the child Scope, release its permit and then run the absolute deadline guard before delivering native success or a catchable native error. Pure caller interruption stays interruption. Host admission also awaits idle ownership and rechecks the deadline. Never hold the permit while waiting in an expired guard. Existing host services, hook order and tool Scopes remain intact.

Core's leaf uses AppProcess/Omni and the qualified constant-e launch boundary: process.execPath, --no-env-file, an owned empty config, fixed script and BUN_BE_BUN=1; no inherited environment beyond the documented Windows system necessities, no shell and no interpolated user code. Requests are data on stdin. Each helper has an owned cwd/config, kill/exit/readers cleanup and its own remaining absolute budget. Validate one versioned response and natural exit; preserve original and cleanup causes. No retry and no fallback when Omni is explicitly disabled or the runtime lacks the qualified capability. A Layer must remain alive around execute, rather than returning a provider whose scope already closed.

The protocol must not silently impose a new semantic result cap or truncate. Existing output bounds are opt-in. Any bounded-memory claim would require a separate reviewed policy; this plan makes none. Stderr/protocol diagnostics remain bounded and private. A reply size/time ownership contract must be explicit before implementation.

Acceptance retains the original twelve CPU/ordinary cases, including 1500ms timeout, heartbeat/phase barriers and natural child exit. Do not increase that timeout or count outer containment as success. Bind the real Core Layer inside the actor process; a parent Layer does not cross a process boundary. Add finite ordinary parity controls separately, plus missing-provider, concurrent execution, error/catch, interruption and cleanup-order cases. Confirm exact runtime/source/compiled capability on the qualified platforms. Then run the full CodeMode package and exact CPU acceptance on hosted CI, with package typechecks serialized locally.

Independent preparatory critique identified the concrete implementation obligations above: actual provider selection, existing diagnostic normalization, every implicit native path, metadata/codec fidelity and join/release/guard ordering. These are requirements, not evidence of an implementation. The four existing Sol agents remain the execution fleet; Root owns the protocol, scaffold, integration and single PR.

## Typed wire seam

Root's native-regex.ts defines version 1 requests for the eleven operations, explicit undefined capture tags, optional groups, UTF-16 offsets, native state, correlated success results and catchable native error replies. decodeReply rejects excess fields, incompatible operation/result pairs and a response naming another request operation. Request split.limit is the already-normalized uint32 value: preserve existing native ToUint32 behavior at the interpreter boundary before encoding. Construction returns canonical source/flags with index zero. Match global arrays differ from a nonglobal match carrying captures/index/groups; split captures retain undefined. Replacement enumeration omits repeated subject strings and callbacks reconstruct their arguments in the parent.

The current interpreter rejects assignment/update of lastIndex through its ComputedValue path. Preserve that restriction; native methods alone mutate the shared instance's state. Preserve the own enumerable regex property without exposing new enumerable metadata. A metadata-only value must never compile a native regex when that property, source, flags, exposed booleans or textual coercion are read. Private metadata and native storage may use nonenumerable/private fields. A guarded regex accessor may throw for metadata-only storage, but all finite execution paths must use metadata-aware access instead.

The first independent wire critique required correlated results plus request/reply equality; Root added both before source GO. CodeMode contract typecheck passed locally; no executor, metadata migration or runtime implementation is claimed yet. The absolute-deadline and twelve original acceptance cases remain unchanged. Exact Core leaf scaffold, fixed script, codecs and acceptance review still precede source packets.

Core leaf scaffold b80e05de39 exports CodeModeNativeRegex.make (requiring the actual AppProcess service) and layer (providing NativeRegex.Executor). Core declares its direct workspace dependency and export; CodeMode imports neither Core nor Server. The adjacent fixed-script scaffold is the only helper program. The provider schema-validates a request before serializing stdin, then uses process.execPath with --no-env-file, an owned empty --config and -e with that fixed script. Child stdout contains exactly one versioned JSON reply; parent strict-decodes it against the request and requires natural successful exit. Native errors are reply data, infrastructure errors fail the Effect. No interpolated code, shell, retry, reusable child or fallback.

Each run owns its temporary cwd/config, process, stdin and joined readers. The remaining finite positive budget wraps the whole resource scope, including spawn and cleanup. AppProcess.run keeps stdout unbounded by default; do not add a new semantic result cap. Stderr is bounded to 16 KiB and truncation/nonzero/protocol errors refuse. No inherited environment except BUN_BE_BUN=1 and available Windows SYSTEMROOT/WINDIR. Explicit Omni off refuses before spawn. The fixed child parses only parent-validated data, performs native operations and emits tagged captures; it never receives callbacks/tools/interpreted programs. Named groups remain raw wire data, then existing blocked-member filtering and null-prototype reconstruction run before callbacks/model access.

Provider acceptance c39c2c8313 has eighteen cases through the real AppProcess seam. This is distinct from decoder tests and the original twelve interpreter/CPU cases. Source GO still requires independent acceptance review. The interpreter migration remains a separate package: optional-provider selection, finite parser path, metadata, per-execute semaphore, and release/join/deadline ordering cannot be inferred from provider success.
