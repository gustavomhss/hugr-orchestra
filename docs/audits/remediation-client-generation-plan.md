# Hosted Client generation for the integrated API and T2

Local generation is not allowed in this campaign. Add a dedicated Core hosted qualification, modeled on the existing Atlas artifact gate, to run the official packages/client bun run generate twice, verify deterministic exact file vectors and preserve downloadable generated bytes. Do not patch emitted files.

Ownership: packages/core/test/client-generated-artifact.test.ts, test/fixture/client-generated-request.ts, test/client-generated-request.test.ts and the narrow .github/workflows/test-ci.yml request-output/upload integration only. The exact normalized request is package core, directory packages/core, runner bun, args [./test/client-generated-artifact.test.ts,--timeout,900000], empty env, no config/benchmarkRenderer. Default/full/unrelated Core runs must not generate. Predicate negatives include extra args/env, wrong directory/runner/file, filters and absent request; the explicitly selected test refuses missing hosted identity/platform.

The producer requires actual Linux hosted CI/run/snapshot identity and verifies git HEAD. Use AppProcess/Omni for all child commands, declare expectSpawn inside the selected test. Commands have finite time/output bounds and must finish without truncation or nonzero exit. Persist stage/provenance before and after each command, including runtime, argv/cwd, output hashes and real exit. Keep unknown failures as failures and qualify only after every owned scope settles.

Before generation record a sorted path/SHA256/byte vector of all tracked files under packages/schema, packages/protocol, packages/client and tooling/httpapi-codegen excluding the two generated directories, plus root package.json, bun.lock and bunfig.toml when present. These readonly source inputs and locks must match after the entire qualification. Discover tracked generated files and actual final generated directory entries safely; reject symlinks/path escapes. Record before, first and second output vectors; require first==second, including file names. The official writer owns only packages/client/src/generated and src/generated-effect.

After the second generation, execute scoped Client Promise and Effect tests and codegen tests against those installed generated outputs, then run official Client check:generated. Verify installed bytes remain equal to the second vector and readonly input hashes unchanged. Copy only produced files plus provenance under test-ci-evidence/client-generated; verify artifact hashes equal installed outputs and exact inventory. All filesystem work joins every outcome before failure; no partial-success proof. Max overall900000ms includes children and cleanup. Copy no secrets, node_modules or credentials.

Workflow reads the same exact predicate and publishes client_generated output. Upload only for that explicit request on Linux, always including failure evidence when available, using the existing pinned upload-artifact action with if-no-files-found:error and7day retention. Other workflows remain untouched. Root independently checks run/jobs/logs, snapshot input vectors and archive manifest before recovering exact generated files and committing provenance. Recovery never accepts arbitrary ZIP paths, missing/extra files, wrong snapshot/input hashes or unqualified proof. Final installed Client typecheck and original real Server envelope BOTH gate qualify behavior; generator lifecycle evidence alone does not close T2.

The official check:generated compares against Git's index. Because this qualification intentionally produces changed bytes, use an owned temporary GIT_INDEX_FILE seeded from HEAD and stage only the first/second identical generated outputs there before that command. This proves regeneration leaves those produced bytes unchanged; it does not claim the original snapshot already contained them. Pass the temporary index only to the actual child commands, record this environment boundary and remove it after joined cleanup. Hash the actual repository index before/after and require it unchanged. Never stage the real index, commit or update refs from the harness.
