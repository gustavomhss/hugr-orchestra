# Final integration extraction plan

The cold epic 43427741510 exposed nineteen godfile failures. This plan precedes implementation. Root retains architecture and integration; four existing Sol agents own disjoint files. No waiver is added or increased, no assertions are removed, and whitespace compression is excluded. The gate counts nonblank lines: new files stay below750, legacy files above750 cannot grow relative to the merge base, and existing waiver maxima remain unchanged.

## Frozen boundaries

1. Desktop and Claude host: move the complete owned-serve test family into `owned-serve.test.ts`, sharing only the existing pure `until` fixture. Keep actors, thresholds, spawn declarations and cleanup unchanged. Move Live's locale dictionaries and existing locale selection to `renderer/live/copy.ts`. Move the host's `Tracker`, event conversion and private context-window calculation to `v2/events.ts`, with the existing `MCP_PREFIX` passed explicitly. Keep query, governed gate, Scope and background ownership in the host. Move its last self-contained delivery receipt test into a separate test file; share only pure frame/usage/user/ports/turn helpers, never mutable SDK state.

2. CodeMode and TUI: move the entire existing top-level `invokeStringMethod` into `stdlib/string-method.ts` with the same signature and body. Every finite regex closure, per-execution semaphore, lazy request factory, state commit, callback and absolute deadline stays in `runtime.ts`. Move only pure prompt support types/functions/constants into `component/prompt/support.ts`, preserving public type reexports. Extract the exact Sync store initializer into `createSyncStore()` called at the original point; all ownership maps, hydration and IO remain in the provider. Move only the top-level `Option` component into `dialog-select-option.tsx`.

3. Core: move durable event read/codec helpers into `event/read.ts`, preserving existing public reexports and error identity. Move only the MCP diagnostic HTTP probe and server-info parser into `mcp/debug.ts`; configured lookup, errors, auth generation and connection ownership stay in the parent. Move Session's read methods into `session/read.ts`, taking existing db/events/store and a lazy `get` callback; retain the same decoder for fork. Move pure prompt normalization into `session/resolve-prompt.ts`. Move only runner compact/generate methods into `runner/auxiliary.ts`, receiving existing services without creating a layer or Scope. Keep provider streaming and durable admission/continuation ownership unchanged. Move two exclusive-wake coordinator tests intact into a new test file; move Task's shared fixture definitions intact into `fixture/tool-task.ts`, keeping repository lifetime and all cases in the original file.

4. App: extract pure Session page-merging helpers into `server-session-pages.ts`; all maps, generations, stores and IO closures remain in `createServerSession`. Share existing pure test constructors in a fixture and move the first three complete reconnect cases to a new test file. Extract Session route-frame/provider components intact into `session-route-frame.tsx`, preserving component identity, provider order and mounting boundaries. Move only the native prompt-retry harness into its own fixture, preserving actor resolution, actual processes and all three native test bodies. Extract the complete captured-submission execution body into `createSubmissionExecutor(environment)`, instantiated once per existing submitter. Pass the existing hook/service identities and original capture callback; invocation receives the exact already-captured object. Never recapture, recreate an owner/query/controller, or move mutable admission/retry state to a new lifetime. The pending-job map moves once into a single shared leaf with its existing helpers; both follow-up and composer use that singleton. Shell transport becomes a separate leaf to avoid a runtime cycle. Preserve existing public exports through the original entrypoint.

Root owns shared architecture declarations and removal of any waiver made stale by a legitimate extraction. Agents stop for a changed contract or a final count that misses the bound. Private helper interfaces mirror existing values and function signatures; no new public package API or runtime dependency is authorized.

## Acceptance and integration

Every moved test keeps its name, body, assertions, timeout and spawn declaration. Focused hosted requests must name both original and extracted test files. Production moves require package typechecks, independent cold review, `check:godfile`, boundaries, spawn imports and guards. Runtime qualification must include the original CodeMode CPU pack, App admission/retry/epoch cases, Session coordinator/Task cases, real Desktop process cases and Claude host cases. Generated input manifests are rechecked after the moves; official hosted generation is refreshed where inputs changed. The final epic is rerun only after all integration repairs and their scoped gates are green. One PR remains the delivery boundary.
