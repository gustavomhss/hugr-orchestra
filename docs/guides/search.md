# Search

**Search** in the sidebar (inside the Advanced group) does not open a page. It opens the command palette, one box that finds commands, sessions and files. The sidebar entry shows the shortcut and is greyed out when the palette is not available.

## Open it

- Choose **Search** in the sidebar.
- Press `⌘K` on macOS or `Ctrl+K` elsewhere. `⌘⇧P` / `Ctrl+Shift+P` also works. You can change both under **Settings > Shortcuts**.
- Use the search button in the title bar. It is off by default; turn it on with **Command palette** under **Advanced** in **Settings > General** (see [Advanced settings](settings-advanced.md)).

## What you find

Type to filter. With nothing typed, the palette lists common commands first, then the files you have open.

| Place | Placeholder | Results |
| --- | --- | --- |
| Inside a project | **Search files, commands, and sessions** | **Commands**, sessions, and **Files** |
| On Home | **Search commands and sessions** | **Commands** and sessions. With nothing typed, the first five commands. |

If nothing matches, it says **No results found**.

Commands that have a keyboard shortcut show it on the right of the row. Archived sessions appear dimmed.

## Pick a result

Move with the arrow keys and press `Enter`, or click. A command runs. A session opens. A file opens in the file tab of the current session. `Esc` closes the palette without doing anything.

## Atlas has its own search

On the [Atlas screen](atlas-screen.md), `/` opens a different search that covers facts, files, areas, memory and Atlas pages.
