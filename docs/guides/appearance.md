# Appearance

Appearance covers how Orchestra looks: its color theme, the photo behind the glass, and the fonts. You set it in **Settings**, in **General**, under **Appearance**. These are app settings, not project settings.

## Theme

**Theme** changes colors only. The glass, layout and type stay Orchestra's. Pick one of:

- **System**
- **Dark**
- **Light**
- **Graphite**
- **Gruvbox**
- **GitHub**
- **Nord**
- **AMOLED**

## Background

**Background** is the photo behind the glass. Choose one from the grid of photos. **Orchestra** is the default.

The page explains: **The photo behind the glass. Text contrast is tuned for the default photo, so darken brighter ones.** Use the **Darken** slider, which goes from 0 to 80%, to dim the photo until the text reads well.

## Fonts

Three rows set the fonts:

| Row | Used for |
| --- | --- |
| **UI Font** | The font used throughout the interface. |
| **Code Font** | The font used in code blocks. |
| **Terminal Font** | The font used in the terminal. |

## Limits

- Themes recolor the app. They do not change layout, spacing or the glass effect.
