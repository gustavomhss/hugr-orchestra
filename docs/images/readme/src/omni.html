omni

Every child process belongs to a tree, and a separate supervisor owns the trees.

The app talks to omni through a native addon. The addon starts a supervisor process on first use and hands it each spawn over a private channel.

App or server host

Only one module imports omni. Output pipes are drained with backpressure: the pump pauses at 8 MiB per stream instead of dropping bytes.

hugr_omni.node (napi)

Supervisor hugr-omni-supervisor

Started with --host-pid. Owns up to 4,096 trees. Watches the host and stops everything it owns when the host dies.

Unix

Root is a session leader. Stop sends SIGTERM (and SIGHUP to a PTY) plus SIGCONT, waits the grace, then SIGKILL swept every 10 ms. Linux pins the root with a pidfd. A process that calls setsid itself escapes.

Windows

Each tree is a Job object with kill-on-close that refuses breakaway. Stop sends CTRL_BREAK, then TerminateJobObject. .cmd and .bat run through cmd.exe.
