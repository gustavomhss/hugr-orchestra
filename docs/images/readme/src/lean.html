Lean

Tool output is shrunk before it enters the context, and the original stays one call away.

Three stages run in order on every native tool result. Lean only acts on results the size bound left whole, and a Lean error falls back to the plain output.

Tool result

bash, read, webfetch, grep, glob

1. Secrets

AWS keys, GitHub tokens, live Stripe and project keys, PEM blocks are caught before anything else.

2. Size bound

Over 2,000 lines or 50 KiB: the model gets a hint and a file path to page through. Lean is skipped.

3. Lean

One of 20 profiles strips known noise. Errors, failures and stack traces stay.

bash: over 4 KiBread, webfetch: over 8 KiB
