Atlas ledger

What each task cost, in your repository's own history.

When the merge queue lands a bundle it commits a record to .atlas/: who worked on each card, with which engine and model, how many tokens, tool calls and minutes, and the verdict. It lives in git, so it travels with the code and can be read with plain tools.

The record commit

chore(queue): record <label>

Merge commits on the base branch carry WP: and Attempt: trailers that point back here.

Layout

.atlas/
  project/ orientation, review, board (.jsonl)
  members/<seat>/ each seat's own memory
  cards/<CARD>/
    card.jsonl the card's history
    attempts/a<n>.jsonl one file per attempt
  blobs/ large bodies, by hash
Every line is content-hashed.

Public repositories

The line keeps its hash; spend is dropped before it is written. Model cost never goes to GitHub. The board's Money panel shows it from the local database instead.

Budgets

A seat with no meter shows not metered, never zero. Warn at 80% of the budget, ask at 90%, pause at 100%; an attempt over three times the median is flagged.
