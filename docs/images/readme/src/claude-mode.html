Claude mode

Maestro's turn runs inside Claude Code; Orchestra keeps the rules.

Turn it on in Settings › Providers › Claude mode. Claude Code signs in with your own account (claude auth login --claudeai); Orchestra stores no credential.

Session runner

Admits your prompt, loads context and history, persists every event.

One provider turn = one host.stream call.

Execution host

Starts Claude Code with a stable session id, sends Orchestra's context on each prompt and only when its hash changes.

Claude Code query()

Keeps the claude_code system prompt preset; Orchestra adds only an appendix. Claude Code owns compaction.
