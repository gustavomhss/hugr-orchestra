Landing

The full suite runs once per bundle, not once per change.

Each card proves itself with scoped checks first. The merge queue then bundles green cards, runs the full suite once on the bundle and lands it with a plain merge. The host moves cards; no agent can push a card into the queue.
1 · Review

Card with a pull request

The seat's branch and its evidence: what changed, decisions, what is not covered, risk.

2 · Scoped checks

Green at the head commit

Only the tests the change touches, run on CI. A new commit resets it.

3 · Queue

Admitted by the host

Refused without a PR, with open follow-ups, or while the queue is paused.

4 · Bundle

4 cards by default

Up to 16, or whatever is waiting after 45 minutes.

7 · Record

chore(queue): record <label>

Each attempt's cost, time and verdict go to .atlas/ in git.

6 · Land

Local merge, fast-forward

Merge commits carry WP: and Attempt: trailers. Cards move to Shipped.

5 · Full suite, once

The whole bundle on one CI run

Every package, every OS lane. Green lands all cards together.

green: landred: split
When the bundle is red

Halve and bisect

Run each half until the red card is found.

Red card goes back

Only the card that is red on its own returns to Review. The rest land.

Infrastructure failure

A runner or network failure is rerun once, not blamed on a card.

Red base

If the base branch itself is red, the queue opens a bug card for it.
