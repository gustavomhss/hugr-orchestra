# Guardrail pilot catalog: validation against history

Window: last 300 commits of `origin/dev` (cbabfb537a back to 865cad63d4, 2026-10-19), one `git log -p -U0` pass. 88,289 added lines, 2,075 file entries. Read-only: no tests, builds or installs. Scanner and raw extracts are in the session scratchpad, not in the repo.

How to read it
- "Hits" = added lines (or paths/modes) matching the detection in the window. FP = the hit was legitimate when read.
- Verdicts: keep-gate, keep-warn (already warn and holds), demote, tighten (pattern or scope change, severity unchanged unless said), cut, not measurable (nm).
- Volume of the window by language: TS/TSX about 79.6k added lines, Python 93, Rust 28, SQL 0, workflow YAML 58. So Python and Rust rules have no signal here; they are nm, not "clean".
- Positive control: my first scan returned 0 for S3/S4/D2/X3/X4 because of a broken path regex; `: any` clearly existed in the data, so I fixed the regex and reran. The numbers below are from the fixed run.
- Baseline (HEAD of origin/dev, `git grep`) is used only to judge whether a rule would fire on code people routinely touch.

## Engine-level findings (apply to many rules)

1. Moved code shows up as added lines. The LSP move (c7440fff69, 1706e0d4fe) and the V1 protocol removal (3764a71dde) re-add old lines. The engine must diff with rename detection (`-M`) and skip lines identical to a deleted line in the same PR, or S3/S4/D2 fire on moves.
2. Generated and vendored files dominate the added-line count (`packages/sdk/js/src/v2/gen/*`, `packages/client/src/generated*`, `modules/atlas/boundary/src/generated/*`, `packages/app-shell/src/v2-wire.ts`, `v2-legacy*.ts`). Every line rule needs a shared generated-path exclusion. Without it S3 is 145 hits, with it 19.
3. Merge commits are real on `dev` (42 "Merge pull request" subjects in the last 600, plus Merge branch / remote-tracking merges). Title and conflict rules must treat them explicitly.
4. A big part of history is intentional bulk work (V1 removal, regen chains). Rules that compare removed vs added (T6) need a per-commit escape.
