# @orchestra/app

The shared Solid application library behind Orchestra's UI: routing, providers, server state, settings, commands, localization and platform-neutral behavior. The desktop renderer and the browser bootstrap both import it, so the UI is written once. The package directory is `packages/app-shell`; the package name is `@orchestra/app`. For the product picture see [architecture](../../docs/guides/architecture.md).

## Who uses it

`apps/desktop` (renderer) and `apps/web` (browser bootstrap and web build).

## Boundaries

- Host behavior sits behind the `Platform` contract and providers. `apps/web` supplies browser storage, notifications, navigation and server URL; `apps/desktop` supplies native integrations through its preload API.
- Electron main-process code, Node-only adapters, IPC and packaging stay in `apps/desktop`. Shared UI must not import them.
- Talks to the server through [`@orchestra/client`](../client/README.md); it must not import Core.

## Entry points

The `exports` map in `package.json` is the supported surface. The root (`@orchestra/app`) exposes providers (`AppBaseProviders`, `PlatformProvider`), `AppInterface`, components, hooks and platform types. Named subpaths cover host integrations and assets: `/web`, `/desktop-menu`, `/updater`, `/live`, `/native-titlebar`, `/orchestra/brand`, `/i18n/desktop-native`, `/vite` and `/index.css`. Internal `src/` modules and the `@/` alias are not public. When adding a shared capability, decide root versus subpath and update `exports`.

Layout: `public/` static assets, `src/i18n` and `src/context/language` for locales, `src/index.css` and feature style files for styling. Visual rules are in the repository `orchestra-design-system` skill.

## Commands

Web (from `apps/web`): `bun dev` (Vite on port 3000), `bun run build`, `bun run serve`. Set `VITE_ORCHESTRA_SERVER_HOST` and `VITE_ORCHESTRA_SERVER_PORT` to point at a backend.

From `packages/app-shell`:

```sh
bun typecheck                 # tsgo -b
bun run test:e2e:local        # Playwright; starts the Vite server from apps/web
bun run test:e2e:local -- --grep "settings"
```

Playwright defaults: base URL `http://127.0.0.1:3000`, backend `127.0.0.1:4096`; override with `PLAYWRIGHT_PORT`, `PLAYWRIGHT_BASE_URL`, `PLAYWRIGHT_SERVER_HOST`, `PLAYWRIGHT_SERVER_PORT`. `PLAYWRIGHT_FULLY_PARALLEL=1`, `PLAYWRIGHT_EXECUTABLE_PATH` and `PLAYWRIGHT_NO_VIDEO=1` are also read. Run `bunx playwright install chromium` once. Unit and browser tests run on CI from the repository root: `bun run test:ci app`. Policy is in [AGENTS.md](../../AGENTS.md).
