Search file contents with a regular expression in ripgrep syntax, such as `function\s+\w+` or `TODO|FIXME`.

- `path` is a directory or a single file, the working directory by default. `include` limits the search to file names that match a glob, such as `*.ts` or `*.{ts,tsx}`.
- Matching is case-sensitive and works line by line; start the pattern with `(?i)` to ignore case.
- Hidden files are searched; files and directories excluded by `.gitignore` are not.
- The result lists matching lines with their line numbers, grouped by file, and stops at 100 matches. For complete counts or file lists, use `bash`, for example `git grep -c` or `rg -l`.
