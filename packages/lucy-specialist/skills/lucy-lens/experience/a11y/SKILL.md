# Accessible interaction

Inspect changed controls for accessible names, roles, keyboard operation, focus and state announcements where the implementation exposes them. Identify the user action, affected control and violated stated requirement. Raise `class:experience.a11y` for an evidenced barrier; an unseen assistive-technology outcome is a question.
