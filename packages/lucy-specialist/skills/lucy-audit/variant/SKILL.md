# Variant analysis

A confirmed finding is the seed, not an analyzer hit or an author's assertion. Identify the exact pattern and trigger shown by its evidence. First search for the known instance; if it does not match, the search is not a trustworthy instrument. Then generalize one element at a time and examine each match in context, including the guard or caller that could make it safe. A similar spelling is a lead, not a finding.

Record the seed, revision, pattern change, examined matches and which were noise. The approved audit limit is at most three generations, stopping when more than half the matches are noise; exactly half does not meet that stop rule. These are host limits, not guarantees this text can enforce. If the host has not supplied the capability or limit enforcement, mark variant work not run rather than assume authority.

A surviving candidate still needs a written rule or property, location, trigger and labelled evidence before confirmation. Report uncertain matches as questions and any budget-limited matches as not examined.
