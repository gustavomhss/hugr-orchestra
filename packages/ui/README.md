# @orchestra/ui

Solid component library with themes, i18n, fonts, audio and Tailwind styles.

## Purpose and ownership

- Base components (`packages/ui/src/components`), hooks and context, the theme system (`packages/ui/src/theme`, with JSON themes), locale files (`packages/ui/src/i18n`), fonts, audio and icon sprites (`packages/ui/src/assets`), and the Tailwind and v2 styles. The v1 and v2 components are both current.
- Every Solid screen builds on it; `packages/session-ui` and `packages/app-shell` add the session and app layers.

## Public entry points and consumers

- Explicit keys (for example `./button`, `./theme`, `./styles`, `./styles/tailwind`) plus the asset wildcards `./fonts/*`, `./audio/*`, `./v2/*.css` and `./v2/styles/*`.
- Consumers: `packages/app-shell` (most imports), `packages/session-ui`, `apps/storybook`, `packages/tui` and `apps/desktop`.

## Dependencies and boundaries

- Layer `ui`.
- No workspace dependencies.

## Assets, schemas and generated files

- `bun run generate:tailwind` (`packages/ui/script/tailwind.ts`) writes `packages/ui/src/styles/tailwind/colors.css` from `packages/ui/script/colors.txt`; `bun run generate:v2-oc2` (`packages/ui/script/build-oc2-v2-overrides.ts`) rewrites the v2 overrides in `packages/ui/src/theme/themes/oc-2.json`. Run them from `packages/ui`; do not edit their output.
- Fonts, audio, icons and images live in `packages/ui/src/assets`.

## Persistence, identity and lifetime

- The theme context stores the chosen theme in the browser's `localStorage` when it is available; nothing else persists.

## Commands

- `bun typecheck` from `packages/ui`.
- `bun run build` from `packages/ui` (type declarations to `dist`).
- `bun run test:ci ui <files>`
- Stories run in `apps/storybook`.

## Contracts and verification limits

- Keep `packages/ui/AGENTS.md` (every visible string uses an i18n key) and `packages/ui/LICENSE`.
- Visual output is checked in Storybook and the apps, not by tests.
