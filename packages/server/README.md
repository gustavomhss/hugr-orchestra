# @orchestra/server

Adapts Orchestra's typed Protocol API to Effect HTTP. Handlers translate request context and declared errors at the HTTP edge and delegate to Core services. Relay authoring goes through `@orchestra/relay` (`src/relay-documents.ts`).

Dependencies run Schema -> Core and Protocol -> Server.

## Who uses it

`apps/cli` (standalone `createRoutes()` server), `packages/sdk-next` (in-process `createEmbeddedRoutes()`), and `packages/app-shell` (types).

## Entry points

The export map names modules directly, for example `@orchestra/server/routes`.

- `src/api.ts`: builds `Api` from Protocol's `makeDefaultApi` with location and session-location middleware.
- `src/handlers.ts` and `src/handlers/`: endpoint groups bound to Core services.
- `src/routes.ts`: HTTP layer assembly. Exports `createRoutes({ password?, host?, operator?, verifier? })`, `createEmbeddedRoutes({ host?, operator?, verifier? })` (no password), the default `routes` layer and `webHandler()` for Fetch-compatible hosting.
- `src/auth.ts` and `src/middleware/authorization.ts`: Basic authorization when a password is set.
- `src/location.ts` and `src/middleware/session-location.ts`: resolve the request's Location, or a Session's stored Location.
- `src/middleware/schema-error.ts`: maps schema rejection to the declared invalid-request error.

Product modules reach these routes only through `Host.Contribution` values from `packages/core/src/host.ts`. `Host.merge` rejects a contribution that would own the Session execution, Session, Location map or scheduled-task nodes, so each process keeps one coordinator.

## Commands

From this directory:

```sh
bun typecheck
bun run test:httpapi   # HTTP contract coverage script
```

Tests run on CI from the repository root: `bun run test:ci server`. Contract tests live in `test/`.

## Limits

After changing the Server `HttpApi` or Protocol, run `bun run generate` in `packages/client`.
