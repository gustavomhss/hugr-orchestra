# Go

## Applicability

An assigned change to a Go service component. The frozen tuple is Go 1.25 or later with `net/http` and `context`, chi `v5.3.2`, pgx `v5.8.0` (`github.com/jackc/pgx/v5`) and code generated by sqlc `1.31.1` with `sql_package: pgx/v5`. The packet's `go.mod` pins govern; where they differ from this tuple, the version notes below are unverified for that project.

After this card, read only the references the assigned component uses:

- [chi router](../frameworks/go/chi.md): routes registered on `github.com/go-chi/chi/v5`.
- [pgx](../libraries/go/pgx.md): native pool, connection or transaction access.
- [sqlc generated queries](../libraries/go/sqlc.md): calling sqlc output built for pgx/v5.

The general procedures in [cancellation](../lifetimes/cancellation.md) and [atomic writes](../data/transaction.md) still apply; this card gives their Go form.

## Non-trigger

- A module that merely appears in `go.mod` or a vendor tree. Select by the component the packet assigns.
- Choosing a router, driver, ORM or generator, or raising the `go` line or a dependency to reach a newer helper. Each is a `packet` blocker.
- Gin, Echo, Ent or `database/sql` components: no reference is authored for them. Follow the packet and the surrounding code.

## Inputs

- The module path, the `go` and `toolchain` lines, and the build tags the checks use.
- The packages and files to change, and the existing patterns to follow.
- Request deadlines, cancellation behavior and the error-to-response mapping.

## Steps

1. Pass `context.Context` as the first parameter through handler, service and repository. In a handler, start from `r.Context()`. Never store a context in a struct or start a request path from `context.Background()`.
2. Derive deadlines with `context.WithTimeout` and call `defer cancel()` on the next line. Cleanup that must outlive a canceled request uses `context.WithoutCancel(ctx)` wrapped in its own bounded timeout.
3. Keep presence apart from zero. A required field whose zero value is valid is a pointer (`*int`) in the request DTO, checked for `nil` before conversion to the domain type.
4. Decode JSON from a bounded body with a strict decoder:
   ```go
   r.Body = http.MaxBytesReader(w, r.Body, limit)
   dec := json.NewDecoder(r.Body)
   dec.DisallowUnknownFields()
   if err := dec.Decode(&in); err != nil {
       var tooBig *http.MaxBytesError
       // errors.As(err, &tooBig) → 413; any other decode error → 400
   }
   if err := dec.Decode(&struct{}{}); err != io.EOF {
       // trailing value or garbage after the object → 400
   }
   ```
5. Classify errors with `errors.Is` and `errors.As`, never by message text. Wrap with `fmt.Errorf("create task: %w", err)` so callers can still match.
6. Write the response only after the commit succeeded. Set headers before `WriteHeader`; after the first write the status cannot change.
7. Join every goroutine you start before the function returns: `sync.WaitGroup` (its `Go` method needs a `go 1.25` line) or the project's existing `errgroup`. Never share one transaction or connection between goroutines.

## Tools and outputs

- Scoped to the packet's packages: the project's formatter (`gofmt -l`), `go vet`, and `go test -count=1`; add `-race` when concurrency is assigned.
- Outputs: handwritten handler, service, repository and test code. Generated code is regenerated from its inputs, never edited.
- Toolkit engines, only for the artifacts the packet assigns: [sqlc](../recipes/external/sqlc.md) to regenerate query code, [ast-grep](../recipes/external/ast-grep.md) for bounded syntax rewrites, [buf](../recipes/external/buf.md) for Protobuf schema checks, [kiota](../recipes/external/kiota.md) for API clients from an OpenAPI description.
- The standard `ServeMux` (Go 1.22 patterns) registers `"POST /projects/{projectID}/tasks"` and reads `r.PathValue("projectID")`. A chi component uses chi's API instead.

## Limits and checks

- `httptest.NewRequest` carries a background context. To test cancellation, cancel a context attached with `req.WithContext`. A recorder call never emulates a client disconnect; use `httptest.NewServer` for that claim.
- Test through the real router's `ServeHTTP` whenever routing, middleware or path parameters matter.
- `go test` caches passing results; `-count=1` makes a rerun real evidence. Compiling and `go vet` are not behavior evidence.
- `GODEBUG=httpmuxgo121=1` or a `go` line below 1.22 restores the old `ServeMux` matcher, and method patterns stop working.
- A `GET` pattern on `ServeMux` also serves `HEAD`.
