# Web and literature sources

## Choose the source

Prefer the primary source: the project's own documentation, release notes, specification, source repository or the paper itself. A blog, forum answer or summary is a lead to that source, not evidence on its own.

Pin the version and the date. Match documentation to the version in use: read the lockfile or manifest first, then the docs or tag for that version. Note when the page has no version or date, and when an abstract, HTML and PDF of one paper disagree. Never pick the convenient number.

## Read the actual object

Read the methods, results and limitations, not only the introduction or abstract. Say whether you read the full text, the abstract only or a secondary account. For a benchmark or result, identify the dataset and evaluator version, the population, the comparator, the metric and its uncertainty.

## Separate metrics and conclusions

Accuracy, precision, recall, citation support, latency and cost answer different questions. A correctly attributed claim can still be false or not apply here. Check denominators and aggregation. An inconclusive difference is not proof of equality, and one significant metric does not transfer to another.

## Ablations

State the exact change between arms, and check that model, tools, sources, budget, prompts and retries were held constant. Count setup and failed attempts in cost where the source reports them; otherwise say the cost is unknown. A small pilot shows failure modes, not general superiority.

## Transfer proportionally

Report the result under its conditions, then state the inference that carries it to this question and label it inference. "This setting suggests X; whether it holds here needs a matched test" is honest. "This method is best" from an unrelated dataset is not.

## Reviews

Name the method you actually performed. A handful of selected papers is a narrative review, not a systematic one. Record the queries, sources and date of the search, and keep excluded and inaccessible material visible with its reason. Do not pool incompatible estimates or count positive studies as votes. Missing evidence is not evidence of no effect.
