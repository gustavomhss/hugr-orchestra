# Explore a field and sharpen its questions

Read when the brief asks what exists, which approaches matter, how a territory is organized or what is worth investigating. An incomplete exploratory brief is valid. Do not demand a prewritten complete scope; do not use exploration to avoid answering a known precise fact or ranking alternatives against supplied criteria.

## Inputs and discriminating questions

Use the initial interest, intended reader/use, permitted source universe and effort limit. Establish a provisional boundary from the brief and early sources. Ask: which distinction changes the reader's next question, which category is missing a credible example, and what frontier remains outside the examined scope?

## Procedure

1. Start with a few applicable primary anchors, not a universal source quota. Use exposed search for candidates and follow references from useful originals. Read representative mechanisms and counterexamples rather than accumulating titles.
2. Build provisional categories by purpose, mechanism, assumptions or evidence type. A vendor list is not a field map. Test whether the categories explain real differences; revise overlaps or empty categories instead of forcing sources into a predetermined taxonomy.
3. Let reading generate follow-up questions. Follow a branch only if it resolves an important distinction, exposes a rival approach or changes the promising frontier. Keep excluded branches recoverable.
4. Retain material discoveries and category conditions through shared [corpus](../../jimmy-discovery/references/corpus.md). Link findings with reasons; `related` is navigation, not evidence of superiority. Do not create a note for every source or build an index/graph service.
5. Connect categories: which problem leads to which mechanism, what assumptions separate alternatives, and which questions now merit analytical/comparative work? An unfamiliar technique is not automatically an opportunity or better solution.

## Tools, evidence and failure

Use permitted acquisition, verified Own and native records/views. Search snippets and generated overviews orient but do not replace originals. State inaccessible full text, non-primary accounts, version boundaries and language/platform exclusions. Preserve contrary examples that change categories.

If search breadth is unsupported, describe a bounded map of examined sources rather than “the field”. Permission denials/Own holds remain verbatim blockers. Continue independent allowed branches only when they do not depend on missing evidence.

## Writing and closure

Use genre `map` and [map writing](../writing/map.md). Explain the organizing distinction before listing families. For each important family connect its purpose, mechanism, representative support and limit; end with questions justified by the map.

Stop when the reader has useful distinctions, connected examples and an explicit covered frontier, or at the effort bound. New sources that only repeat established categories are not a reason to continue; a material new category may be. Do not claim exhaustiveness from thematic repetition. Close with promising next questions and truthful coverage using [closure](../../jimmy-discovery/references/closure.md).
