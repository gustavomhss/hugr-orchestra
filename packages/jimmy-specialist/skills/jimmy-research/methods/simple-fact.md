# Resolve a simple fact

Read for a bounded factual question: an official rule, default, limit, supported version or precise exception. Do not turn this into a dossier, literature review or comparison. A contested mechanism, broad field or decision between alternatives needs its corresponding method.

## Inputs and discriminator

Use the exact question, applicable version/scenario and permitted primary source. Resolve missing version from available context; ask only if different applicable versions change the answer. Ask: which clause answers this wording, and which exception would change it for this scenario?

## Procedure

1. Open a known official source with permitted `read`, `webfetch` or `research_capture`. If its origin is unknown, use available search to find it and read the original. A snippet is a lead, not the retained answer source.
2. Check version, scope and source completeness. Read the nearby definition, footnote, table and exception rather than extracting a headline alone. If converted text omitted the decisive table, retrieve a permitted retained representation that contains it; denied access remains a blocker, not a workaround request.
3. Retain the native capture receipt and exact locator through shared [acquisition](../../jimmy-discovery/references/reading-tools.md). A simple fact needs evidence but not a question/finding graph, independent reviewer, outline or fabricated Memory lesson.
4. Answer the exact question with the material qualification and source attribution. Distinguish what the official contract states from what an unobserved installed runtime does.

## Selection, failure and closure

Use profile `research`, depth `quick`, genre `answer`; omit modality because there is no `simple` modality value. Profile `evaluate` is appropriate if the task is instead validating a supplied bounded claim. Increase effort only for a concrete conflicting source, unresolved exception or applicability question.

If a source is partial, stale, inaccessible or unsuitable, retain the actual failure and answer only the supported part. If the official clause is ambiguous, state the two readings and exact missing clarification; do not claim a rule from intuition. Missing retained bytes mean no promised recoverability.

Use [answer writing](../writing/answer.md). Stop after the question and decisive exception are supported, or after an essential source/qualification is unavailable. Follow [closure](../../jimmy-discovery/references/closure.md), with real evidence references and no mandatory document for a one-paragraph answer.
