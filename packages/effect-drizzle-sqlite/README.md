# @orchestra/effect-drizzle-sqlite

Adapter that lets Drizzle's SQLite query builders run as Effects: yieldable selects, inserts, updates, deletes, raw queries and transactions, with Drizzle's schema and query APIs unchanged. Core uses it for the Orchestra database.

It builds on the generic `effect/unstable/sql/SqlClient` service. It does not open a database or pick a native driver; the host provides a SQLite `SqlClient` (Core picks the Bun or Node one per runtime).

## Who uses it

`packages/core` only.

## Entry points

- `@orchestra/effect-drizzle-sqlite`: `EffectDrizzleSqlite` (`make`, `makeWithDefaults`, `migrate`), `EffectSQLiteDatabase`, `EffectLogger`, session exports.
- `.../effect-sqlite`: database and session APIs.
- `.../effect-sqlite/migrator`: Drizzle migration helper.
- `.../sqlite-core/effect`: Effect-yieldable query builders.

```ts
import { SqliteClient } from "@effect/sql-sqlite-bun"
import { EffectDrizzleSqlite } from "@orchestra/effect-drizzle-sqlite"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const db = yield* EffectDrizzleSqlite.makeWithDefaults()
  return yield* db.select().from(users)
}).pipe(Effect.provide(SqliteClient.layer({ filename: "app.db" })))
```

`make` requires `SqlClient`, `EffectLogger` and `EffectCache`; `makeWithDefaults` supplies Drizzle's default logger and cache.

`EffectDrizzleSqlite.migrate(db, { migrationsFolder })` runs Drizzle SQL migration files and records them in `__drizzle_migrations`, upgrading the legacy journal schema when needed. Core's TypeScript schema and data migrations stay in Core.

## Commands

From this directory: `bun typecheck`. Tests run on CI from the repository root: `bun run test:ci effect-drizzle-sqlite test/sqlite.test.ts`.

## Limits

Public names follow Drizzle's Effect SQLite adapter so consumers keep familiar identities. See [AGENTS.md](./AGENTS.md) for contributor rules.
